# Правила оформлення програмного коду

1. Використовувати зрозумілі назви змінних і функцій.
2. Дотримуватися єдиного стилю форматування коду.
3. Додавати коментарі до складних ділянок програми.
4. Перед кожним комітом необхідно перевіряти правильність оформлення програмного коду.
5. Видаляти невикористані змінні та зайві файли.
6. Використовувати зрозумілі повідомлення комітів.
